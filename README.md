Every test is green. Every single one. And yet the product does not work at all — not even a little, not even by accident. This entry is a one-liner excuse for that impossible situation: a single funny line, under 140 characters, that explains how a test suite can pass with flying colors while the thing it was supposed to protect is completely broken. The joke is judged by an AI model jury, so the line has to land fast — no setup, no second sentence, just the punchline. It is the kind of excuse a developer blurts out in a standup while everyone already knows the deploy is on fire.

## Run it

```bash
python3 main.py
```

The program writes its excuse line to `/output/entry.txt`.
